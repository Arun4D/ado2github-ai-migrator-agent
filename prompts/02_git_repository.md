======================================================
GIT REPOSITORY MIGRATION
======================================================

Migrate the Git repository and its history from Azure DevOps to GitHub Enterprise.

Supported Objects:
- Repositories
- Git history
- Branches
- Tags
- Git LFS
- Submodules
- Repository Policies
- Branch Policies

Target Objects:
- Repositories
- Branch Protection Rules

Orchestrator Tools:
- clone_repository
- mirror_repository
- create_github_repository
- push_repository

Validation:
- Validate repository migration
- Validate commit history
- Validate branches
- Validate tags
