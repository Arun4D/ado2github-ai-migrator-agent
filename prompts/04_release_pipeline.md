======================================================
RELEASE PIPELINE MIGRATION
======================================================

Migrate and translate Azure DevOps Classic Release and Deployment Pipelines to GitHub Actions.

Supported Objects:
- Classic Release Pipelines
- Deployment Groups
- Stages
- Jobs
- Tasks
- Deployment Strategies
- Service Connections
- Environments
- Approvals
- Checks
- Deployment Gates

Target Objects:
- GitHub Actions Workflows
- Reusable Workflows
- Composite Actions
- GitHub Environments

Orchestrator Tools:
- discover_release_pipelines
- create_workflow
