======================================================
BUILD PIPELINE MIGRATION
======================================================

Migrate and translate Azure DevOps Build Pipelines to GitHub Actions.

Supported Objects:
- Classic Build Pipelines
- YAML Pipelines
- Stages
- Jobs
- Tasks
- Pipeline Templates
- Artifacts
- Feeds
- Schedules
- Triggers
- Microsoft Hosted Agents
- Self-hosted Agents
- Container Jobs
- Pipeline Permissions
- Pipeline Dependencies
- Pipeline Parameters
- Pipeline Expressions
- Conditions

Target Objects:
- GitHub Actions Workflows
- Reusable Workflows
- Composite Actions
- Workflow Templates
- GitHub Hosted Runners
- Self Hosted Runners
- Runner Groups

Orchestrator Tools:
- discover_build_pipelines
- discover_yaml_pipelines
- create_workflow
